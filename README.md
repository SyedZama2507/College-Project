# 🎓 College Web Application

A simple static college website developed using HTML and CSS. This project represents a basic multi-page website for a college, including information about admissions, courses, and contact details.

---

## 🚀 Features

* 📄 Multiple web pages (Home, About, Contact, Admission, etc.)
* 🎥 Media support (images & videos)
* 📱 Simple and user-friendly design
* 🌐 Easy to run in any browser

---

## 🛠️ Tech Stack

* HTML5
* CSS3

---

## ▶️ How to Run

1. Download or clone the repository
2. Open the project folder
3. Double-click on `index.html`

OR

Right-click → Open with browser
